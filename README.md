# 📚 Exercícios de Java — Laços de Repetição

Repositório com 10 exercícios práticos de Java, cobrindo estruturas de repetição (`while`, `do while` e `for`).

## 📌 Sobre

Os exercícios simulam cenários simples do dia a dia (contagem, tabuada, vendas, caixa registradora, login e menu de sistema), praticando os conceitos de forma progressiva.
